# Support

## Public open source

- **Bugs and features** — open an issue on the canonical repository (`nubit-symfony`, `nubit-react`, `nubit-skeleton`, `nubit-agent`).
- **How do I…** — start a Discussion on that repository if Discussions are enabled; otherwise an issue tagged `question`.
- **Security** — [SECURITY.md](SECURITY.md) only.

Read-only package splits do not take issues. Use `nubit-symfony`.

## Commercial / private products

If you are a Nubit customer (eFact, hosting, a custom system), do not use public GitHub issues for account, billing, or production incidents. Use the support channel in your contract or [nubit.io](https://www.nubit.io).

Private repositories are not a public support inbox.
